# Portfolio Development Instructions

This repository contains my personal AI / Machine Learning / Data Science portfolio.

Before making architectural or visual changes, read:
PORTFOLIO_SPEC.md

Core requirements:

- AI, Machine Learning and Data Science are the primary identity.
- Personal content must remain separate from UI components.
- Never invent projects, metrics, experience or qualifications.
- Maintain responsive behaviour from 320px through large desktop screens.
- Use TypeScript and maintain clean component boundaries.
- Prefer Server Components unless client-side behaviour is required.
- Respect reduced-motion preferences.
- Do not sacrifice performance for decorative effects.
- Run lint and production build checks after significant changes.
- Update CONTENT_GUIDE.md when the content structure changes.
